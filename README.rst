SQLiTables
==========
SQLiTables is a Python library for managing SQLite databases with object-oriented concepts.
It is built on top of standard Python module `sqlite3 <https://docs.python.org/3/library/sqlite3.html#module-sqlite3>`_ with no third-party
dependencies for ease of use.

Installation
------------
This library is simple to install through PyPI.

1. Ensure a supported version of Python is installed.
2. Type the following in the command-line interface:

.. code-block:: bash

    pip install sqlitables
